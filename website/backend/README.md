# Motion AI Plugin - Laravel API

Backend API for the Motion AI After Effects plugin. Handles license verification, user authentication, plugin downloads, admin management, and update distribution.

## Requirements

- PHP 8.2+
- MySQL 8.0
- Composer 2.x
- Docker & Docker Compose (for local development)

## Quick Start (Docker)

```bash
# Clone the repository and navigate to backend
cd backend

# One-command setup
make setup
```

This starts all services, installs dependencies, generates an app key, runs migrations with seeders, and creates the storage symlink.

- **API:** http://localhost:8000
- **Adminer (DB GUI):** http://localhost:8080 (server: `mysql`, user: `motion_ai`, password: `secret`)

## Manual Setup (Without Docker)

```bash
# Install PHP dependencies
composer install

# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Run migrations and seed the database
php artisan migrate --seed

# Create storage symlink
php artisan storage:link

# Start the development server
php artisan serve
```

## Environment Variables

| Variable                | Description                              | Default / Example              |
|-------------------------|------------------------------------------|--------------------------------|
| `APP_NAME`              | Application name                         | `Motion AI`                    |
| `APP_ENV`               | Environment (local, production)          | `local`                        |
| `APP_KEY`               | Encryption key (auto-generated)          | `base64:...`                   |
| `APP_DEBUG`             | Enable debug mode                        | `true`                         |
| `APP_URL`               | Base URL of the API                      | `http://localhost:8000`        |
| `DB_CONNECTION`         | Database driver                          | `mysql`                        |
| `DB_HOST`               | Database host                            | `mysql` (Docker) / `127.0.0.1` |
| `DB_PORT`               | Database port                            | `3306`                         |
| `DB_DATABASE`           | Database name                            | `motion_ai`                    |
| `DB_USERNAME`           | Database user                            | `motion_ai`                    |
| `DB_PASSWORD`           | Database password                        | `secret`                       |
| `CACHE_STORE`           | Cache driver (file, redis, database)     | `file`                         |
| `QUEUE_CONNECTION`      | Queue driver (sync, database, redis)     | `sync`                         |
| `SESSION_DRIVER`        | Session driver                           | `file`                         |
| `MAIL_MAILER`           | Mail driver (smtp, mailgun, ses)         | `smtp`                         |
| `MAIL_HOST`             | SMTP server host                         | `mailpit` (Docker)             |
| `MAIL_PORT`             | SMTP server port                         | `1025`                         |
| `MAIL_USERNAME`         | SMTP username                            | `null`                         |
| `MAIL_PASSWORD`         | SMTP password                            | `null`                         |
| `MAIL_FROM_ADDRESS`     | Default sender email                     | `noreply@motionai.com`         |
| `CORS_ALLOWED_ORIGINS`  | Comma-separated allowed CORS origins     | `http://localhost:3000`        |
| `SANCTUM_STATEFUL_DOMAINS` | Domains for Sanctum cookie auth       | `localhost:3000`               |
| `GUMROAD_PRODUCT_ID`   | Gumroad product ID for license checks    | (your product ID)              |

## Make Commands

| Command            | Description                                     |
|--------------------|-------------------------------------------------|
| `make up`          | Start all Docker containers                     |
| `make down`        | Stop all Docker containers                      |
| `make build`       | Rebuild Docker images (no cache)                |
| `make shell`       | Open a bash shell in the app container          |
| `make migrate`     | Run database migrations                         |
| `make seed`        | Run database seeders                            |
| `make test`        | Run the test suite                              |
| `make fresh`       | Drop all tables, re-migrate, and seed           |
| `make logs`        | Tail container logs                             |
| `make setup`       | Full first-time setup (build, migrate, seed)    |
| `make composer *`  | Run any Composer command (e.g., `make composer require laravel/sanctum`) |
| `make artisan *`   | Run any Artisan command (e.g., `make artisan make:model Post`)           |
